# 数字语音模型上板说明（RA6M5 + Keil）

## 1. 语言要求（必须）
- 当前模型 `digit_model_int8.tflite` 使用 TensorFlow Lite Micro（TFLM）推理。
- TFLM 核心接口是 C++，因此 Keil 工程必须启用 C++ 编译单元。
- 可执行方式：项目主体保留 C，AI 推理模块使用 C++，并通过 `extern "C"` 暴露 C 接口给 C 文件调用。

## 2. 固定上板文件
- `digit_model.c`
- `digit_model.h`

文件作用：
- `digit_model.c`：模型二进制数组 `g_digit_model_data[]`
- `digit_model.h`：模型数组与长度声明
- 模型长度：`g_digit_model_data_len = 301088` 字节

## 3. 模型固定参数（必须一致）
模型文件：`digit_model_int8.tflite`

输入张量：
- shape: `[1, 40, 120, 1]`（NHWC）
- dtype: `int8`
- quantization: `scale = 0.0235825814306736`, `zero_point = -47`

输出张量：
- shape: `[1, 10]`
- dtype: `int8`
- quantization: `scale = 0.00390625`, `zero_point = -128`

类别映射：
- 输出下标 `0~9` 对应数字 `0~9`

算子（Resolver 必须注册）：
- `CONV_2D`
- `MAX_POOL_2D`
- `RESHAPE`
- `FULLY_CONNECTED`
- `SOFTMAX`

## 4. PC端训练流程

### 4.1 数据读取
- 从 `data/0` 到 `data/9` 读取全部 `.wav`

### 4.2 音频预处理
- 重采样：`16000 Hz`
- 单声道
- `top_db = 40` 能量阈值截取有效语音
- 前后保留 `0.03 s`
- 目标长度 `1.2 s`（`19200` 点）
- 长于 1.2s：中心裁剪
- 短于 1.2s：左右补零
- 峰值归一化：`audio = audio / max(abs(audio))`

### 4.3 特征提取（Log-Mel）
- STFT 参数：
- `n_fft = 512`
- `win_length = 400`
- `hop_length = 160`
- `window = hann`
- Mel 参数：
- `n_mels = 40`
- `fmin = 20 Hz`
- `fmax = 7600 Hz`
- `log_mel = log10(max(mel, 1e-10))`
- 时间帧固定 `120`：不足补零，超出截断
- 单样本标准化：`(x - mean) / (std + 1e-6)`

### 4.4 训练网络（当前固定）
- `Conv2D(12, 3x3, relu)`
- `MaxPool2D(2x2)`
- `Conv2D(16, 3x3, relu)`
- `MaxPool2D(2x2)`
- `Conv2D(24, 3x3, relu)`
- `Flatten`
- `Dense(40, relu)`
- `Dropout(0.10)`
- `Dense(10, softmax)`

训练参数：
- `RANDOM_SEED = 44`
- `EPOCHS = 40`
- `BATCH_SIZE = 16`
- `LEARNING_RATE = 1e-3`
- EarlyStopping：`monitor=loss`, `patience=5`, `min_delta=1e-4`
- ReduceLROnPlateau：`monitor=loss`, `factor=0.5`, `patience=2`, `min_lr=1e-5`

## 5. PC端测试流程

### 5.1 单数字测试流程
1. 录音（默认 1.5s）
2. 调用与训练一致的 `extract_feature_from_audio` 做预处理和特征提取
3. 输入量化：
4. `q = round(x / 0.0235825814306736 - 47)`
5. 裁剪到 `[-128, 127]`
6. TFLM 推理
7. 输出 10 类概率，取 argmax 得到数字

### 5.2 四位连续测试流程
1. 录音（默认 4.8s）
2. 先做 `audio = normalize_audio(audio - mean(audio))`
3. 生成分段候选：
4. VAD 参数组：
5. `(ratio=0.10, pctl=58, dil=2, ero=1)`
6. `(ratio=0.13, pctl=65, dil=2, ero=1)`
7. `(ratio=0.16, pctl=72, dil=1, ero=0)`
8. 能量峰值分段：
9. 平滑窗口 `0.08 s`
10. `min_peak_distance = max(0.22 s, avg_digit_len * 0.45)`
11. `prominence = max(percentile70 * 0.15, 1e-5)`
12. 规范成 4 段：
13. 段数多于 4：合并最小间隔相邻段
14. 段数少于 4：切分最长段
15. 每段再做：
16. 前后扩展 `0.04 s`
17. `trim_and_fit(..., top_db=40)` + `normalize_audio`
18. 提取特征并推理
19. 候选打分：
20. `score = 0.65*mean_conf + 0.35*min_conf - 0.10*std_conf`
21. 取最高分候选，输出 4 位数字字符串

## 6. Keil 工程固定接入步骤
1. 把 `digit_model.c`、`digit_model.h` 加入 Keil 工程
2. 在 C++ 推理模块中加载模型：`tflite::GetModel(g_digit_model_data)`
3. 按第 3 节注册算子并创建 `MicroInterpreter`
4. 分配 `tensor_arena` 并执行 `AllocateTensors()`
5. 按第 5 节流程送入特征并执行推理

## 7. 一致性要求
- 板端参数必须与本文一致，不允许改动采样率、时长、STFT、Mel、量化参数
